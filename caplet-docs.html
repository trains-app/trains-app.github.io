Caplets

Generate MRT/LRT station caplets from a station code. Colours come from the line variables in global.css, so nothing is drawn by hand.

1. Setup

Include the stylesheet and the script. The script also exposes the functions on window.

<link rel="stylesheet" href="styles/global.css">
<script src="scripts/caplets.js"></script>

Caplets are inline SVGs with the class caplet-svg. Control their size with CSS; width follows automatically.

.caplet-svg { height: 28px; width: auto; }   /* already in global.css */
The text uses the local LTA-Identity font declared in global.css. Font size and alignment are set inline on each caplet, so they are not affected by the .caplet-svg text rule.

2. Two ways to create a caplet

In HTML: data-caplet

Any element with data-caplet is replaced by a caplet when the page loads. Classes on the element are copied to the caplet.

<span data-caplet="NS22"></span>

In JavaScript: createCaplet()

Returns an <svg> element you can insert anywhere.

document.querySelector("#station-list").append(createCaplet("NS22"));

Elements added after page load are not picked up automatically. Call hydrateCaplets(container) on the container that holds new data-caplet elements.

list.insertAdjacentHTML("beforeend", '<span data-caplet="DT11"></span>');
hydrateCaplets(list);

3. Code formats

Codes are case-insensitive, and a space between the letters and number is optional. Text is displayed as NS 22.

InputResultNotes
NS22Station code
TE22ASuffix letter after the number
JS2ASuffix letter after the number
NSLine prefix only
NSLFull line name only
XX9Unknown prefix: grey fallback

4. Interchange caplets

Give several codes separated by /, a comma or a space (or pass an array). They are drawn as one caplet with a shared outline, in the order given.

<span data-caplet="NS25/EW13"></span>
<span data-caplet="CC1/NE6/NS24"></span>

createCaplet("NS25/EW13");
createCaplet(["CC1", "NE6", "NS24"]);

5. Tap-out-to-transfer caplets

Add data-caplet-transfer (HTML) or { transfer: true } (JS), or use createTransferCaplet(). The caplets stay separate and are joined by a connector split in the two line colours. Two or more codes are supported.

<span data-caplet="DT11/NS21" data-caplet-transfer></span>

createCaplet("DT11/NS21", { transfer: true });
createTransferCaplet("DT11", "NS21");
createTransferCaplet(["DT11", "NS21"], { outline: "#fff" });

6. Custom colours

Pass fill, outline and textColor. Any CSS colour works, including variables such as var(--brand-500).

OptionHTML attributeApplies to
filldata-caplet-fillThe coloured shape(s). String for all, array for per-segment (null keeps the line colour).
outlinedata-caplet-outlineThe larger shape behind. Default white. One value for the whole caplet.
textColordata-caplet-textThe label. String or array like fill.
transferdata-caplet-transferTap-out-to-transfer layout.

In HTML attributes, separate array values with | (for example data-caplet-fill="#123456|#abcdef"; leave an entry empty to keep the default).

If you set a custom hex fill without textColor, the text switches between dark and light for contrast. For non-hex fills (such as CSS variables) the line's default text colour is used, so set textColor yourself if needed.

<span data-caplet="NS22" data-caplet-fill="#FFD100" data-caplet-outline="#2E2A25"></span>
<span data-caplet="NS25/EW13" data-caplet-fill="#123456|"></span>

createCaplet("NS22", { fill: "#FFD100", outline: "#2E2A25" });
createCaplet("NS25/EW13", { fill: ["#123456", null] });
createCaplet("NS22", { fill: "var(--brand-500)", textColor: "#fff" });

7. Sizing

Caplets are SVGs with a fixed viewBox (116 units tall; the width depends on how many codes it has). The outline, shapes, text and connector are all drawn in those units, so everything scales together and the proportions never change. Set the height with CSS and the width follows automatically.

.caplet-svg { height: 28px; width: auto; }   /* default, in global.css */
.caplet-svg { height: 1.6em; }               /* scale with the surrounding font-size */
.station-title .caplet-svg { height: 40px; } /* larger in one place */

Classes on a data-caplet element are copied onto the SVG, so you can size individual caplets:

<span data-caplet="NS22" class="size-l"></span>
Caplets never stretch. If you set both width and height to a ratio that doesn't match, the caplet stays undistorted and is centred in the box. A caplet's width depends on its number of codes, so an interchange caplet is wider than a single one at the same height. To fix the width instead, set width and leave height as auto; wider caplets will then be shorter.

Functions

Line colours

The prefix picks the colour variable. Full line names (NSL, …) map to the same colour.

Adding or changing a line

Edit the LINES table at the top of caplets.js (and LINE_ALIASES for full names). Set text when a line needs dark text.

const LINES = {
  ...
  XY: { fill: "var(--some-colour)", text: DARK_TEXT },
};
